# IOT Monitor Gas System

> Sistem monitoring gas LPG dan kualitas udara yang mengirim telemetri ke dashboard Blynk.

## ✨ Fitur

- Sensor MQ-6 (LPG) dan MQ-135 (CO2)
- Telemetri ke Blynk
- Kalibrasi dan auto-baseline
- Alarm lokal

## 🛠 Tech Stack

"Arduino / ESP8266" "Blynk" "MQUnifiedsensor" "PlatformIO"

## 🚀 Menjalankan

```
buka dengan PlatformIO
sesuaikan token Blynk di kode
```

## 📌 Catatan

Proyek ini merupakan bagian dari portofolio pribadi. Kode disusun untuk kebutuhan nyata,
bukan sekadar demo, sehingga sebagian konfigurasi spesifik lingkungan mungkin perlu
disesuaikan sebelum dijalankan.
